CHAINNE API

A clean API for launching automations and retrieving results.

Use the API to trigger workflows, post structured inputs, and receive rich event responses from your deployed agents.

Example request

curl -X POST https://api.chainne.ai/v1/workflows/run \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"workflow":"lead-qualification","input":{"source":"webform"}}'

Supported actions include workflow execution, webhook dispatch, and audit log retrieval. Explore the docs for full payload examples and response models.
